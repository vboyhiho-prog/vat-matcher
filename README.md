# VAT Matcher v1.56 Portable

This repository retains one public release only: VAT Matcher v1.56 Portable.

Download the complete package from [GitHub Releases](https://github.com/vboyhiho-prog/vat-matcher/releases/tag/v1.56).

The ZIP contains the macro-enabled workbook, matching-engine launcher and its
required runtime. Extract the complete folder and keep `engine` next to
`VAT_Matcher_v1.56.xlsm` before opening the workbook.

SHA-256: see `VAT_Matcher_v1.56_Portable.zip.sha256`.
